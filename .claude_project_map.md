## 🎯 To Work on ui_testing_automation:

```bash
cd ui_testing_automation
claude code
```

Claude will automatically load the project-specific CLAUDE.md and understand:
- The project architecture (3-layer design)
- Module dependencies and rules
- Available commands and workflows
- Known issues and workarounds

## 📋 Other Projects

If you need to work on other projects in this directory, you should:
1. Create a project-specific CLAUDE.md in that directory
2. Copy and adapt the .claude folder configuration
3. Run claude_setup.py to verify the environment

## ⚠️ Common Pitfall

When starting Claude Code from the parent `ai_apps` directory, Claude might get confused about which project you're working on. Always:
1. Navigate to the specific project directory first
2. Start Claude Code from there
3. Reference the project-specific CLAUDE.md
