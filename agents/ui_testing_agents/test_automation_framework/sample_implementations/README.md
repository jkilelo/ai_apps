# V2 LLM-Native Examples

This folder contains 5 real-world working examples that showcase the capabilities of our V2 AI agents using **LIVE LLM integration**.

## Important: LLM Required

These examples demonstrate the V2 system's **mandatory LLM integration**. The system will halt if no LLM is available - there are NO fallbacks or mocks.

## Examples

### 1. E-Commerce Checkout Test (`01_ecommerce_checkout_test.py`)
Demonstrates AI-powered test generation for e-commerce checkout flows:
- Shopping cart validation
- Payment processing tests
- Form validation scenarios
- Promo code testing
- Multi-step checkout flows

### 2. Banking Security Test (`02_banking_security_test.py`)
Security-focused test generation for banking applications:
- OWASP Top 10 compliance tests
- Authentication and authorization
- SQL injection and XSS testing
- Rate limiting verification
- Penetration test scenarios
- Constitutional AI validation for ethical testing

### 3. Social Media Platform Test (`03_social_media_test.py`)
Complex social interaction testing:
- Real-time feed updates
- User engagement metrics
- Content moderation tests
- WebSocket event testing
- Visual regression tests
- Infinite scroll and lazy loading

### 4. API Integration Test (`04_api_integration_test.py`)
Comprehensive API testing suite:
- REST endpoint testing
- GraphQL query validation
- WebSocket connection tests
- Contract testing (Pact)
- Performance and load testing
- Microservices integration

### 5. Accessibility Compliance Test (`05_accessibility_compliance_test.py`)
WCAG 2.1 AA compliance testing:
- Screen reader compatibility (NVDA, JAWS, VoiceOver)
- Keyboard navigation tests
- Color contrast validation
- Cognitive accessibility
- ARIA attributes testing
- Section 508 compliance

## Prerequisites

1. **API Keys Required** - Set up in `.env` file:
```env
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
GOOGLE_API_KEY=AIza...
```

2. **Python Dependencies**:
```bash
pip install openai anthropic google-generativeai python-dotenv
```

## Running the Examples

Each example can be run independently:

```bash
# Run from the python_nexus_browser directory
python workplace_agents_v2/examples/01_ecommerce_checkout_test.py
python workplace_agents_v2/examples/02_banking_security_test.py
python workplace_agents_v2/examples/03_social_media_test.py
python workplace_agents_v2/examples/04_api_integration_test.py
python workplace_agents_v2/examples/05_accessibility_compliance_test.py
```

## Troubleshooting

If examples fail to run:

1. **Check API Keys**: Ensure `.env` file has valid API keys
2. **Network Connection**: LLM APIs require internet access
3. **Rate Limits**: Some APIs have rate limits
4. **Python Version**: Requires Python 3.7+
