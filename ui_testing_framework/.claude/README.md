## Usage

### Quick Start
```bash
# Test environment
python .claude/claude_advanced.py

# Optimize a prompt
python .claude/prompt_optimizer.py optimize my_prompt.txt

# Run security audit
python .claude/claude_advanced.py secure module.py

# Check performance
python .claude/claude_advanced.py metrics
```
