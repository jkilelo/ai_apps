ENCODING ISSUES TO PREVENT:
- UnicodeEncodeError: 'charmap' codec can't encode character
- UnicodeDecodeError in Windows terminals
- Broken output in logs and CI/CD systems

ENFORCEMENT:
- Use only ASCII characters (0-127)
- Always use the replacements above
- Test all strings with .encode('ascii')
- Never trust that Unicode will work on all systems
