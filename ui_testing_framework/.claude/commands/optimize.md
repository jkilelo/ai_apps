# /optimize - Performance Optimization Command

## Strategy: Self-Consistency with Multiple Paths

### Path 1: Time Complexity Optimization
Analyze the current code for time complexity bottlenecks:
- Identify O(n²) or worse operations
- Look for repeated computations
- Find opportunities for caching
- Suggest algorithmic improvements

### Path 2: Memory Optimization
Analyze memory usage patterns:
- Identify memory leaks
- Find unnecessary object creation
- Optimize data structures
- Implement lazy loading where appropriate

### Path 3: Async/Parallel Optimization
Identify parallelization opportunities:
- Convert synchronous to async operations
- Implement concurrent processing
- Use thread pools or process pools
- Optimize I/O operations

## Convergence
Combine insights from all paths to create an optimal solution that balances:
- Execution speed
- Memory efficiency
- Code maintainability
- Scalability

## Implementation
Generate optimized code with:
- Performance benchmarks
- Before/after comparisons
- Detailed comments on optimizations
- Test cases to verify correctness
