## 🔥 Quick Start

```python
from nexus_browser import NexusBrowser, NexusConfig

# Configure NEXUS
config = NexusConfig(
    stealth_level="maximum",
    quantum_enabled=True,
    swarm_size=6,
    evolution_generations=5
)

# Initialize browser
async with NexusBrowser(config) as nexus:
    # AI-driven navigation
    result = await nexus.navigate(
        goal="Find and summarize latest AI breakthroughs",
        url="https://news.ycombinator.com"
    )
    
    # Extract data with swarm intelligence
    data = await nexus.extract_data([
        "article.title",
        "div.content"
    ])
    
    # Think about complex problems
    solution = await nexus.think(
        "How to optimize web scraping for this site?"
    )
```
